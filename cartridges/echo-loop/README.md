# echo loop

A precision platformer where every failed run returns as an echo.

**Controls:** Left/right move · A jumps and wall-jumps · B records the current loop

Cross eight compact rooms with tight movement, spikes, wall jumps, and instant restarts. Up to three previous attempts replay at once. Echoes are dangerous after their brief phase-in, but they can also remain on switches to open the exit.

Later rooms require deliberately recording paths so multiple echoes hold switches while the current runner reaches the door.
